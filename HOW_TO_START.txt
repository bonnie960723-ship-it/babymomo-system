BabyMomo Elderly Fitness System - How to Start
==============================================

STEP 1: Install Python (if not installed)
-----------------------------------------
1. Go to https://www.python.org/downloads/
2. Download Python 3.11 or 3.12
3. During install, CHECK the box "Add Python to PATH"
4. Finish install, then close and reopen any command windows

STEP 2: Start the system
------------------------
In the backend folder, open PowerShell and run:

  python -m venv venv
  .\venv\Scripts\Activate.ps1
  pip install -r requirements.txt
  uvicorn main:app --host 0.0.0.0 --port 8000

When you see "Uvicorn running on http://0.0.0.0:8000"
open browser: http://localhost:8000
